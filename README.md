One line of software error copy that tells the user the brutal truth about what went wrong — and makes them laugh on the way. The entry takes the angle most error messages never dare: it admits the bug was caused by our own deploy, eleven minutes ago, and that the fix itself is the bug. It names the real failure in plain words, gives the user something to do (try again in five minutes), and lands a line worth repeating to a colleague: "The fix is the bug now."

> We deployed a fix for this exact bug 11 minutes ago. The fix is the bug now. We're rolling it back — try again in five minutes.

## Run it

```sh
node main.ts
```

This writes the single-line entry (127 characters) to `/output/entry.txt`. No dependencies, no network, Node 22+.
